# Политика конфиденциальности

Политика описывает, как [НАЗВАНИЕ ЮРИДИЧЕСКОГО ЛИЦА] (далее — «Администрация», держатель массива персональных данных) обрабатывает персональные данные Пользователей Платформы [ДОМЕН]. Политика составлена в соответствии с Законом Кыргызской Республики «Об информации персонального характера». Для Пользователей из Европейского союза дополнительно применяются положения раздела 9.

## 1. Какие данные мы обрабатываем

| Категория | Примеры | Источник |
|---|---|---|
| Данные аккаунта | имя или название организации, email, хэш пароля, роль, страна, язык | вводит Пользователь |
| Данные профиля | описание, портфолио, отзывы | вводит Пользователь |
| Данные Заказов | Проекты, Отклики, переписка в чате Заказа, история статусов, суммы | создаются при работе |
| Платёжные данные | идентификаторы платежей и выплат, маскированные реквизиты | от платёжного партнёра |
| Данные согласий | какой документ и какую редакцию принял Пользователь, дата, IP, браузер | фиксируются автоматически |
| Технические данные | IP-адрес, тип браузера, cookie сессии, журналы безопасности | фиксируются автоматически |
| Данные для проверки | копия документа, удостоверяющего личность, — только по запросу | предоставляет Пользователь |

Полные номера банковских карт Администрация не получает и не хранит: их обрабатывает платёжный партнёр.

## 2. Цели и основания

- **исполнение договора** (Соглашения и оферты): регистрация, работа Проектов и Заказов, расчёты, споры;
- **исполнение требований закона**: бухгалтерский и налоговый учёт, противодействие мошенничеству и легализации преступных доходов, ответы на запросы государственных органов;
- **законный интерес**: безопасность Платформы, предотвращение злоупотреблений, разбор жалоб;
- **согласие**: обработка, не охваченная другими основаниями.

Согласие на обработку персональных данных даётся при регистрации и может быть отозвано письмом на [EMAIL]. Отзыв согласия делает невозможным дальнейшее использование Платформы и не влияет на обработку, необходимую по закону.

## 3. Кому мы передаём данные

- **другим Пользователям** — в объёме, необходимом для сделки (имя, профиль, отзывы, переписка по Заказу). Email и телефон другим Пользователям не показываются;
- **платёжным партнёрам** — для проведения платежей и выплат;
- **хостинг-провайдерам и поставщикам почтовых рассылок** — по договорам, обязывающим соблюдать конфиденциальность;
- **государственным органам** — только по основаниям, предусмотренным законом.

Мы не продаём персональные данные.

## 4. Трансграничная передача

Серверы Платформы могут располагаться за пределами Кыргызской Республики ([СТРАНА ХОСТИНГА]). Передача осуществляется в страны, обеспечивающие адекватный уровень защиты, либо на основании согласия Пользователя, которое даётся при регистрации.

## 5. Сроки хранения

| Данные | Срок |
|---|---|
| Аккаунт и профиль | пока аккаунт активен, затем 3 года после удаления — для разрешения претензий |
| Заказы, переписка, споры, согласия | 5 лет после завершения Заказа |
| Платёжные и учётные данные | в течение сроков, установленных налоговым и бухгалтерским законодательством |
| Технические журналы | до 12 месяцев |

## 6. Права Пользователя

Пользователь вправе:
- получить сведения о своих персональных данных и порядке их обработки;
- потребовать исправления неточных данных;
- потребовать удаления данных, если их обработка не требуется по закону или для разрешения споров;
- отозвать согласие;
- обжаловать действия Администрации в уполномоченный орган по защите персональных данных или в суд.

Запросы направляются на [EMAIL]. Срок ответа — не более 30 дней.

## 7. Защита данных

Пароли хранятся только в виде криптографического хэша. Передача данных шифруется (HTTPS). Доступ сотрудников ограничен ролями, действия Модераторов и Администрации журналируются.

## 9. Пользователи из Европейского союза (GDPR)

9.1. Для Пользователей, находящихся в ЕС/ЕЭЗ, Администрация действует как контролёр данных в смысле Регламента (ЕС) 2016/679 (GDPR). Правовые основания — ст. 6(1)(b) (договор), 6(1)(c) (юридическая обязанность), 6(1)(f) (законный интерес), 6(1)(a) (согласие).

9.2. Дополнительно к правам из раздела 6 Пользователь вправе получить данные в машиночитаемом формате, ограничить обработку, возразить против обработки на основании законного интереса и подать жалобу в надзорный орган своей страны.
